# 🧾 Health Wave Invoice Generator

أداة احترافية لتوليد فواتير PDF من ملفات Excel، مصممة خصيصاً لشركة **Health Wave**.

## 🚀 كيفية التشغيل

1. **تثبيت المتطلبات:** قم بتشغيل ملف `setup.bat` لتثبيت المكتبات اللازمة.
2. **التشغيل:** قم بتشغيل ملف `run.bat`.
3. **الاستخدام:**
   - أدخل بيانات الشركة في قسم الإعدادات (يُحفظ مرة واحدة).
   - أدخل اسم العميل ورقم الفاتورة.
   - ارفع ملف Excel (يجب أن يحتوي الصف الأول على العناوين).
   - اضغط على "توليد وتحميل الفاتورة".

## 📋 متطلبات النظام

- نظام تشغيل Windows.
- Python 3.10 أو أحدث.
- **ملاحظة:** يعتمد البرنامج على `WeasyPrint` لتوليد الـ PDF، والذي قد يتطلب تثبيت [GTK3 Runtime](https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases) على نظام ويندوز إذا لم يكن موجوداً.

## 📁 هيكل المشروع

- `core/`: يحتوي على منطق القراءة والتوليد (Excel, PDF, Config).
- `templates/`: يحتوي على قالب الـ HTML (Jinja2).
- `assets/`: مجلد الصور (اللوجو).
- `app.py`: الواجهة الرسومية (Streamlit).
